# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub Security Advisories:
https://github.com/Refactr-io/Factr-I/security/advisories/new

Do not open a public issue or pull request for a vulnerability, and do not
post details publicly until a fix has been released.

Include the affected version, steps to reproduce, and the impact you expect.
We aim to respond within 7 days.

## Supported versions

Factr-I is pre-1.0 (`v0.x`). Only the latest release receives security fixes.
